# Frituritaks - Fishmonger 

This mod adds the Fishmonger, an aquatic custom survivor.

## Note

This mod is the creation of Frituritaks "Freya" (BananaMoray) helped by SmoothSpatula, is it not a complete or final version of the Fishmonger.
Since the progress on the sprites has been halted for now, we have decided to release this *Work In Progress* version of the mod.

Some alternative and boosted skills are missing, this rendition isn't fully accurate to the original character.
The balance has been tried but not fully tested, and some interactions may behave in mysterious ways.
Unluckily for the more stylish players, there are no skins yet.
